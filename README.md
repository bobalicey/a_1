# 黄金矿工

无需第三方依赖的 HTML、CSS、JavaScript 小游戏，支持电脑和触屏。

## 运行

下载仓库并解压，直接双击 `index.html` 即可玩。也可在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在运行服务器的同一台电脑浏览器打开 `http://127.0.0.1:8000`。

## 玩法

- 点击“开始游戏”，按空格、方向键 ↓、点击游戏画面或“出钩”按钮发射抓钩。
- 黄金价值随大小增加，但大块黄金拉回较慢；钻石价值 500，石头价值 20 且拉回很慢。
- 每关 60 秒，第一关目标 650 金币，之后每关目标增加 500，金币累计。
- 达到目标后仍可继续采矿，时间结束或矿物全部采完后结算并进入下一关。
- 切换到其他浏览器标签页时暂停；“重新开始”清空进度。

## 文件

`index.html` 页面，`styles.css` 样式，`script.js` 游戏逻辑。
`videos/bearing-rotation.mp4` 是之前生成的轴承旋转视频。

语法检查：`node --check script.js`。
